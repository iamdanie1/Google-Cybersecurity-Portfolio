# Threat Intelligence & Artifact Analysis: VirusTotal & The Pyramid of Pain

## Project Overview
This project demonstrates an incident triage workflow for an alert triggered by a suspicious email attachment at a financial services firm. Acting as a Tier 1 SOC Analyst, I performed static and behavioral threat intelligence analysis on a malicious file artifact using **VirusTotal**. By pivoting across file metadata, network relations, and sandbox execution behaviors, I mapped the extracted Indicators of Compromise (IoCs) to David Bianco's **Pyramid of Pain** framework and mapped the adversary's actions to the MITRE ATT&CK matrix.

---

## Incident Context & Timeline

An automated alert was generated by the internal Intrusion Detection System (IDS) after detecting unauthorized executable files on an employee endpoint.

* **1:11 PM:** Employee receives a spear-phishing email containing a password-protected spreadsheet attachment (password supplied in the email body).
* **1:13 PM:** Employee downloads the file, inputs the password, and extracts the contents.
* **1:15 PM:** Execution of the spreadsheet triggers background creation of multiple unauthorized executable payloads.
* **1:20 PM:** IDS flags anomalous executable activity and routes an alert to the SOC.
* **Target Artifact SHA-256 Hash:** `54e6ea47eb04634d3e87fd7787e2136ccfbcc80ade34f246a12cf93bab527f6b`

---

## Maliciousness Determination & VirusTotal Triage

Upon submitting the SHA-256 hash to VirusTotal, the intelligence report confirmed that the file is **DEFINITIVELY MALICIOUS**.

### Threat Intelligence Metrics:
* **Security Vendors' Ratio:** **50 / 67** security vendors flagged this file hash as malicious.
* **Community Score:** **-210** (indicating high confidence of malicious intent across global security researchers).
* **Vendor Classifications:** Consistently categorized as a **Trojan / Agent / Flagpro** family dropper designed to establish unauthorized access and drop secondary executables onto victim machines.

## Mapped Pyramid of Pain

David Bianco's Pyramid of Pain categorizes Indicators of Compromise (IoCs) based on the level of difficulty an adversary experiences when a security team blocks that specific indicator.

```text
                   /\
                  /  \
                 /    \
                / TTPs \             <- Tough for adversary to change
               /--------\
              /  Tools   \           <- Challenging
             /------------\
            / Network/Host \         <- Annoying
           /   Artifacts    \
          /------------------\
         /    Domain Names    \      <- Simple
        /----------------------\
       /      IP Addresses      \    <- Easy
      /--------------------------\
     /        Hash Values         \  <- Trivial for adversary to change
    /------------------------------\
```
| Pyramid Layer | Pain Level for Threat Actor | Extracted IoC / Finding | Source in VirusTotal |
| :---: | :---: | :---: | :---: |
| TTPs | Tough | **T1566.001**: Phishing (Malicious Attachment) / **T1204.002**: User Execution (Malicious File) / **T1059**: Command & Scripting Interpreter Execution | *Behavior Tab (MITRE ATT&CK Matrix)* |
| Tools | Challenging | Customized Trojan Dropper / Downloader Utility (`Flagpro` malware variant) | *Detection & Behavior Tabs* |
| Network / Host Artifacts | Annoying | Dropped `.exe` files in `%Temp% `directory; anomalous User-Agent HTTP headers during C2 communication | *Behavior Tab (Sandbox Execution Reports)* |
| Domain Names | Simple | Malicious Command & Control (C2) domains registered to deliver payloads | *Relations Tab (Contacted Domains) |
| IP Addresses | Easy | Contacted C2 IPv4 Address (e.g., external server hosting secondary payloads) | *Relations Tab (Contacted IP Addresses)* |
| Hash Values | Trivial | **SHA-256**: `54e6ea47eb04634d3e87fd7787e2136ccfbcc80ade34f246a12cf93bab527f6b` / **MD5**: `a2123...` (Extracted file signatures) | *Details Tab (Basic Properties)* |

## SOC Triage & Mitigation Strategy
1. **Endpoint Isolation (Containment)**: Immediately isolate the infected workstation from the local network via EDR to halt active Command & Control (C2) communications and prevent lateral movement.
2. **SIEM / Firewall Blocklist Enforcement**:
* Ingest the extracted **IP Addresses** and **Domains** into the edge firewall and Secure Email Gateway (SEG) blocklists.
* Add the **SHA-256** and **MD5 Hashes** to the Endpoint Detection and Response (EDR) blocklist to prevent execution across all enterprise endpoints.
3. **Phishing Quarantine**: Search the email gateway for identical subject lines or attachments containing the target SHA-256 hash and purge them from all employee inboxes.
4. **Remediation & Forensics**: Perform a full forensic memory and disk sweep on the compromised endpoint to identify all dropped executable files created after 1:15 PM before re-imaging the machine.
